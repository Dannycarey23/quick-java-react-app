# Fullstack Java & React app

A very quick refresher on Spring Booted Java, setting up API end points and throwing a react front end on it. 
The app submits a students name & location to DB. DB Data is retrieved and presented on the page. 

Stuff used:

- IDE: IntelliJ for the Java, VSCode for react
- XAAMP: Apache server & MySQL database
- API Testing: Postman
- MaterialUI for styling
